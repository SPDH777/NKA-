# S_PDH Retro Phone

Teléfono retro con juegos (Sokoban Nokia Edition, City Bloxx, Race Fever y más).

Abre `index.html` o publícalo con GitHub Pages (Settings → Pages → rama main, carpeta raíz).

## Estructura
- `css/` – estilos
- `js/core/<modulo>/` – núcleo, entrada, modelos, íconos
- `js/games/<juego>/` – cada juego en su carpeta
- `js/apps/<app>/` – cada app en su carpeta
- `js/main/` – arranque final

El orden de carga está en `index.html` (los números de los archivos lo indican). No lo cambies.
